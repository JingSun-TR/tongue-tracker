# 👅 Real-time Tongue Contour Tracker

实时超声波舌位轮廓追踪。通过采集卡将超声波视频输入浏览器，实时提取舌面轮廓线。

## 工作原理

1. 超声波机器 → 采集卡 → 电脑识别为摄像头
2. 浏览器 getUserMedia 捕获视频流
3. 每帧实时图像处理：灰度→降噪→阈值→边缘检测→轮廓提取
4. 轮廓线叠加显示在原图上

## 可调参数

- ROI 区域（限定舌头成像范围）
- 高斯模糊（降噪）
- 二值化阈值
- 边缘检测灵敏度
- 轮廓线粗细
- 暗底超声图反转

## 使用

1. 连接超声波设备到采集卡
2. 打开 https://jingsun-tr.github.io/tongue-tracker/
3. 选择对应摄像头
4. 调整ROI到舌头成像区域
5. 调阈值直到轮廓清晰

## 限制

浏览器端图像处理精度有限。建议配合 DeepLabCut 做后期精确标注，本工具用于实时预览。
